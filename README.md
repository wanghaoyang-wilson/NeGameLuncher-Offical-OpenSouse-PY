# NE Launcher Official Repository, Python Open Source Edition

## 项目简介
NE 启动器，一款自研游戏启动器，完整支持插件生态、自定义脚本、版本校验与社区补丁能力。
本仓库为 Python 开源主线版本，遵循 **GPL‑3.0** 开源协议

> 当前状态：开发迭代中。
> 文档内提及的部分功能若在实际程序中无法使用，代表该功能暂未实现。对此我们表示歉意，相关功能会在后续版本陆续上线补齐。

## 版本标识规则
1. **官方现役版本**
    - 对外名称：`NE Language 官方｜Python开源版`
    - 不携带冗长后缀，为官方原生维护版本。
2. **退役（闭源版）社区衍生强制命名规范（协议要求）**
    `NE Language 官方｜Python开源退役‑主版本号‑修改作者‑修订号`
    示例：`NE Language 官方｜Python开源退役‑6.2‑kuangshi‑1.0`
    - 退役版本禁止伪装成现役官方新版本进行分发倒卖；
    - 二次修改分发必须标注完整名称、修改作者与修订号；
    - 社区改版必须保留原版基础公有 API，保证存量插件兼容；土豆码固定沿用原版数值，禁止私自修改。
3. **此库可免费使用**
    - 可免费使用源代码、编译版本
    - 依托GPL 3.0 使用版本源码，必须开源并在README中说明。
## API 生态规则
1. **公有 API**：承诺**只增不减**，迭代仅新增功能，不会删除、变更已有接口签名，保障插件长期兼容。
2. **私有 API**：无长期兼容保障，内核重构、清理屎山时可删除修改。
3. **弃用流程**
    - 即将删除的接口会打上弃用标识，**保留一整个大版本缓冲期，下个大版本才会移除**；
    - 高呼声接口：评论反馈量大（＞1万）可转正为公有API；热门老牌插件依赖的接口人工评估保留；
    - 误删热门接口：社区反馈后可在下一个小补丁版本紧急补回，无需等待大版本更新。
4. **官方兼容插件**
    专门适配作者弃坑、停止维护但仍有用户使用的老旧插件。
    - 可转发新版接口实现兼容；底层无法兼容时输出友好提示日志，告知用户自行适配或降级使用。

## 开源版专属补丁机制
仅 Python 开源版本内置文件补丁工具，闭源版无此功能。
1. 开发者可调用内置 `API/update.py`，执行 `update.run()` 补充缺失文件，实现磁盘级增量补丁（非内存热篡改）；
2. 更新流程：执行补丁请求 → 交由 `main.exe` 完成更新重启 → **自动删除补丁触发文件，防止无限循环更新**；
3. 官方正式更新优先使用完整文件批量覆盖方案，动态补丁仅作为社区自助应急工具，稳定性不作官方保障。

## 产品线分工
1. Python 开源版：项目主线基准，开放社区贡献、反馈、补丁能力，依托 GitHub 生态维护；
2. .NET 版本：高性能闭源成品，免费使用，自愿发电赞助；现役版本逆向篡改、倒卖将直接追责；维护周期保底半年，Bug 过多可提前退役开源；
3. Python 闭源版 ： 基于开源版不过拥有更多新功能，不受支持即为退役。
4. 退役版本：停止维护后开源，附带自定义衍生分发协议。
